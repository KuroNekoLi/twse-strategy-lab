# 台股策略回測實驗室

以臺灣證券交易所上市標的日行情，對照自訂雙均線與定期定額策略。網站目前提供 0050、0056、2330，日期範圍從 2010 年起。

## 回測假設

- 均線只讀取前一交易日收盤資料，當日收盤執行訊號。
- 每月第一個交易日投入月額；持有資產與未投資現金都列入期末資產。
- 報酬率採時間加權計算；回撤依月末報酬指數計算。
- 佣金和賣出交易稅可調整；預設未套用券商折扣或最低手續費。
- 不計配息與滑價。已知的 0050 單位分割會按官方公告調整歷史價格。
- 歷史模擬僅供研究，不是個人化投資建議。

## API 邊界

瀏覽器呼叫 `POST /api/v1/backtests`。請求與回應格式以及 Spring Boot 搬遷對照見 [`docs/spring-boot-migration.md`](docs/spring-boot-migration.md)。Worker 路由負責輸入驗證、TWSE 資料取得與快取；純策略計算位於 `lib/backtest-engine.ts`，公司行動調整位於 `lib/corporate-actions.ts`。

TWSE 的 `STOCK_DAY` 歷史端點在 2010 年以前不提供查詢，因此介面以 2010 年作為可選最早年份。擴充其他標的或延長期間前，需先補齊公司行動與分割資料，並確認來源資料授權及服務限制。
