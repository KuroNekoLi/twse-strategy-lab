# 台股策略回測實驗室

以臺灣證券交易所上市標的日行情回測策略範本，並與定期定額比較。範本包含雙均線交叉、RSI 均值回歸、布林通道回歸、區間突破，以及可自訂回跌買進與目標報酬賣出的策略。可同時選擇 0050、0056、2330 中最多三檔標的，日期範圍從 2010 年起。

## 回測假設

- 所有技術指標只讀取前一交易日完成的收盤資料，並於當日收盤模擬成交。
- 回跌買進門檻以近 252 個交易日高點為基準；獲利賣出門檻以持倉平均成本為基準。
- 每月第一個交易日投入月額；持有資產與未投資現金都列入期末資產。
- 報酬率採時間加權計算；回撤依月末報酬指數計算。
- 佣金和賣出交易稅可調整；預設未套用券商折扣或最低手續費。
- 不計配息與滑價。已知的 0050 單位分割會按官方公告調整歷史價格。
- 歷史模擬僅供研究，不是個人化投資建議。

## API 邊界

瀏覽器呼叫 `POST /api/v1/backtests`。請求與回應格式以及 Spring Boot 搬遷對照見 [`docs/spring-boot-migration.md`](docs/spring-boot-migration.md)。Worker 路由負責輸入驗證與 TWSE 資料取得；純策略計算位於 `lib/backtest-engine.ts`，公司行動調整位於 `lib/corporate-actions.ts`。

TWSE 的 `STOCK_DAY` 歷史端點在 2010 年以前不提供查詢，因此介面以 2010 年作為可選最早年份。擴充其他標的或延長期間前，需先補齊公司行動與分割資料，並確認來源資料授權及服務限制。
