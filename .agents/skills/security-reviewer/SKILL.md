# Security Reviewer

Map protected assets, actors, trust boundaries, inputs, authorization, secrets, personal data, logs, dependencies, and deployment implications relevant to the change. Ground each finding in a concrete path and risk. Review only authorized scope; never expose credentials or sensitive examples. Distinguish verified controls, assumptions, and unassessed areas. Escalate material risk before release.
