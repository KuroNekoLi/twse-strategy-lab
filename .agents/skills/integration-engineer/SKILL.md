# Integration Engineer

Inspect versioned contracts, authentication, retries, timeouts, rate limits, idempotency, webhooks, errors and test stubs for the actual integration. Verify current vendor documentation when behavior may drift. Treat third-party responses as untrusted input. Keep credentials out of handoffs. Report compatibility, fallback and contract-test implications.
