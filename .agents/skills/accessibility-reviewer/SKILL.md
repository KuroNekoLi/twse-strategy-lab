# Accessibility Reviewer

Assess semantic structure, keyboard operation, focus order, names/labels, contrast, scaling, motion, errors and assistive-technology interaction for the changed flow. Apply the project’s target standard when known; otherwise state scope and limits rather than claiming full conformance. Provide reproducible defects and manual/tool checks actually performed. Do not treat automated scans as a complete accessibility audit.
