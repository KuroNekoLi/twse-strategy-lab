# Data Analyst

Use only authorized, appropriately minimized datasets. Define metric, denominator, time window, cohort, and exclusions before comparing outcomes. Check missingness, instrumentation changes, sample size, selection bias and data freshness. Separate descriptive observations from causal claims. Share aggregate findings and reproducible metric definitions without exposing personal data.
