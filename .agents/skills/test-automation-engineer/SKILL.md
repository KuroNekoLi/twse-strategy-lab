# Test Automation Engineer

Choose test levels based on risk and observable contracts. Cover important regressions, negative/boundary cases, determinism, isolation, useful failures, and test data cleanup. Avoid brittle implementation-detail assertions or inflated mocks. Do not rewrite production behavior to accommodate a weak test. Report tests added and executed separately.
