# 台股策略回測實驗室：功能與 UI/UX 路線圖

更新日期：2026-10-08

## 產品方向

把網站規劃成台股投資研究與練習平台：使用者可以探索市場、研究標的、建立和回測策略、用虛擬資金練習交易、追蹤模擬投資組合，並回顧自己的決策。回測是核心能力之一，不是整個產品的邊界。平台以教育與研究為目的，呈現資料來源、假設、風險與限制，不替使用者下投資結論，也不連結真實下單作為第一階段功能。

## 網站頁面架構

產品應由多個任務明確的頁面組成。首頁可呈現市場概況和使用者最近的研究／模擬狀態，再讓使用者進入各工作區。全站導覽在桌面與手機都保持一致；從標的頁或策略庫進入回測或模擬交易時，保留所選代碼、策略與期間，避免重複設定。

## 本次版本納入

- **五種策略範本：**雙均線交叉、RSI 均值回歸、布林通道回歸、區間突破、自訂回跌買進／目標獲利賣出。
- **策略參數可調：**均線週期、RSI 週期與買賣門檻、布林週期與標準差倍數、突破回看日數、回跌百分比與目標獲利百分比。
- **自訂進出場範例：**以近 252 個交易日高點為基準，回跌達設定百分比時買進；持倉報酬達設定百分比時賣出。規則、參數和成交假設會顯示在結果中。
- **使用者自選標的：**可輸入 4–6 位數台股代碼選擇 TWSE 上市標的，一次比較最多三檔；0050、0056、2330 僅作快捷選項。每個標的同時比較策略與定期定額，支援自訂賣出交易稅。代碼有效但期間無資料時，明確顯示行情不可用。
- **同一組投入條件：**初始金額、每月投入、回測期間與手續費套用到所有比較項目。

## 後續可開發功能總表（38 項）

以下皆為目前版本之後可逐步開發的項目，依資料依賴和使用價值排序：

1. **買進持有基準**（P1）：加入單筆投入後持有的基準線，和策略、定期定額並列，清楚標示各種現金流。
2. **逐筆交易清單**（P1）：記錄訊號日、成交日、買賣價、數量、手續費、交易稅、損益和持有時間。
3. **圖表買賣訊號**（P1）：在股價圖上標出策略進出點，點選訊號可查看當時指標值與觸發規則。
4. **風險績效面板**（P1）：加入勝率、獲利因子、波動度、Sharpe、最大回撤與回撤期間，提供指標定義。
5. **年度與月份報酬分析**（P1）：用報酬表或熱度圖查看策略在哪些月份與年份表現不同。
6. **多策略同場比較**（P1）：同一標的、期間與成本下同時比較 2–4 個策略，並可開關曲線。
7. **回測匯出與可重現分享**（P1）：下載交易與績效 CSV/JSON，或複製含完整參數的分享網址。
8. **買賣條件組合器**（P2）：用指標、比較運算子和參數組成買進／賣出條件，支援 AND/OR 群組與自然語句預覽。
9. **停損、移動停利與部位管理**（P2）：設定停損、移動停利、持有上限、單次投入比例和最大曝險。
10. **自訂策略保存庫**（P2）：複製、命名、保存、重跑與整理常用策略；先支援本機保存，之後再同步帳號。
11. **樣本外與 Walk-forward 檢查**（P2）：分開訓練和驗證期間，並以參數熱圖觀察策略是否過度依賴特定參數。
12. **成交量與波動指標**（P3）：取得 OHLCV 歷史資料後，加入均量、價量、ATR、KD、MACD 和 ADX 等策略條件。
13. **基本面歷史篩選**（P3）：加入營收、EPS、殖利率與 ROE，並以財報實際公告日避免前視偏誤。
14. **法人與籌碼條件**（P3）：串接外資、投信、自營商、融資融券等歷史資料，顯示來源和公告時間。
15. **即時／延遲行情工作區**（P4）：顯示最新成交、漲跌、成交量、更新時間和行情延遲狀態，並支援自選清單與提醒。
16. **最佳五檔與盤中 K 線**（P4）：在來源授權允許後顯示五檔委買委賣、深度圖、分時線與多週期 K 線，並支援技術指標圖層。
17. **代碼／名稱搜尋與標的目錄**（P1）：提供 TWSE 上市標的搜尋、自動完成、名稱與代碼識別、可用歷史期間提示及多選比較；資料目錄需每日更新並標示上市／下市狀態。
18. **多頁導覽與跨頁狀態**（P1）：建立回測工作台、策略庫、標的探索、方法說明等路由；頁面之間帶入標的、策略與期間，支援返回恢復與可分享網址。
19. **虛擬交易帳戶**（P1）：建立一個或多個以新台幣計價的模擬帳戶，可設定起始虛擬本金、開始日和模擬規則；明確標示不涉及真實資金或券商委託。
20. **台股模擬委託與成交**（P1）：支援現股買賣、限價／市價等首批委託類型，考慮整股／零股、漲跌幅、交易時段、手續費與交易稅；若資料頻率不足，不得宣稱是即時撮合或真實成交。
21. **持倉、委託與帳戶帳本**（P1）：檢視可用現金、總資產、未實現／已實現損益、未成交／已取消委託和逐筆成交；每次狀態變更留存可追溯紀錄。
22. **交易日誌與復盤**（P2）：每筆模擬交易可記錄進場理由、採用策略、當時截圖／指標、情緒標籤和事後檢討，支援依策略、標的和錯誤類型整理。
23. **歷史行情逐步回放**（P2）：隱藏未來 K 棒，讓使用者逐根或定速播放歷史行情並模擬下單；保存回放進度與交易結果，避免偷看未來資料。
24. **模擬挑戰與排行榜**（P3）：提供個人任務、好友／公開競賽和固定期間排行榜；排名同時展示報酬、最大回撤、波動和交易規則，避免鼓勵單純冒險衝高報酬。
25. **多組投資組合與自選清單**（P2）：分別管理觀察股、ETF 清單、模擬策略組合和長期投資組合，支援排序、標籤、備註及跨頁帶入。
26. **持倉與股利追蹤**（P2）：手動輸入持有數量、成本、買進日期和現金流，計入股利與已知公司行動，呈現總報酬和現金收入；與虛擬帳戶資料清楚分開。
27. **投資組合匯入／匯出**（P2）：提供 CSV 範本、欄位預覽、格式錯誤提示與匯入前確認；可匯出持倉、成交、股利和績效資料。
28. **資產配置與再平衡分析**（P3）：設定標的權重與再平衡頻率／門檻，比較定期、偏離門檻及不再平衡情境，呈現換手成本和配置漂移。
29. **目標規劃與 Monte Carlo 情境**（P3）：使用者設定每月投入、年限、目標金額與提領情境，以歷史抽樣或明確的假設範圍呈現多種結果分布；不可把機率當成保證。
30. **投資組合壓力測試與相關性**（P3）：呈現相關係數、集中度、歷史下跌情境與敏感度，協助理解多檔標的可能同跌的風險。
31. **可保存的選股篩選器**（P2）：組合技術面、基本面、成交量、ETF 和籌碼條件，保存條件並在更新資料後重跑；每個篩選欄位標明資料日期與可用期間。
32. **自選股價格與策略提醒**（P2）：依價格、漲跌幅、指標或策略訊號設提醒，可一次套用到清單；列出觸發時間、所用資料和通知狀態。
33. **市場廣度與類股輪動**（P3）：查看上漲／下跌家數、創高／創低、類股相對強弱與市場寬度趨勢，說明涵蓋範圍與計算方式。
34. **公司研究頁**（P3）：整合公司簡介、財報、營收、估值、股利、法人籌碼、新聞和價格圖表；歷史研究要依資料實際公布日，避免前視偏誤。
35. **股利、財報與市場事件日曆**（P3）：彙整除權息、股東會、財報／法說公告和總經事件，支援自選標的篩選與提醒，並標記資料來源及公告時間。
36. **循序式學習與練習任務**（P3）：以短課程和情境任務解釋委託、成本、分散、回撤和策略偏誤；完成任務後直接連到歷史回放或模擬帳戶練習。
37. **策略報告分享與版本紀錄**（P2）：分享包含標的、規則、期間、成本、資料版本和績效的唯讀報告；複製或修改策略時保存來源和版本，不把單次高報酬包裝成推薦。
38. **通知中心與研究摘要**（P3）：集中顯示提醒觸發、持倉事件、模擬委託、策略回測完成與資料更新，讓使用者自行設定頻率和通知類別。

### 虛擬交易功能的設計底線

- **先做模擬，不接真實券商下單。**帳戶本金明確標為虛擬資金，任何交易確認畫面都不可讓人誤以為是真實委託。
- **成交模型要說得清楚。**盤後日資料版可以使用下一個可用收盤價等明確規則；若未取得授權即時行情與委託簿，不應模擬即時五檔成交或宣稱成交貼近市場。
- **台股規則可檢查。**依適用標的處理交易時段、價格跳動單位、整股／零股、漲跌幅和費率；規則需可更新並顯示生效版本。
- **帳務由交易事件推導。**委託、成交、取消、費用、股利與公司行動留存事件歷史，支援重算帳戶餘額及稽核錯誤。
- **競賽不只看報酬。**提供回撤、波動、風險調整後績效、交易次數和規則遵循度，並避免排行榜獎勵過度槓桿或集中押注。

## 後續功能優先序

### P1：讓回測結果可解釋

1. **買進持有基準：**將策略同時與定期定額及買進持有比較，清楚標明各自投入現金流，避免把不同投入時點當成完全公平的比較。
2. **交易清單與圖上訊號：**在價格圖上標註買賣點；表格列出訊號日期、成交日期、價格、股數、費用、單筆損益和持有天數。
3. **風險與穩定性指標：**增加交易次數、勝率、獲利因子、波動度、Sharpe、回撤期間；提供年度／月份報酬表與回撤曲線。每個數字附計算說明。
4. **多策略比較：**讓使用者一次選 2–4 個策略範本，在同一標的、期間與成本下比較，並可在曲線圖開關各策略。
5. **匯出與分享：**匯出 CSV/JSON 回測明細；可複製一個包含參數的網址，讓面試官或同事重現同一組結果。
6. **標的探索與跨頁導覽：**標的目錄依代碼／名稱搜尋並帶入回測；建立策略庫和方法說明等獨立路由，導覽列在各頁一致，URL 保留可重現的標的與策略狀態。
7. **虛擬交易最小版本：**先推出新台幣虛擬本金、現股持倉、明確成交規則、交易費用、持倉／委託／成交歷史和總資產曲線；使用者可從回測或標的頁將策略／代碼帶入模擬帳戶。

### P2：建立可組合、可保存的自訂策略

1. **條件式策略編輯器：**提供「買進條件」和「賣出條件」兩個區塊；每個條件由指標、運算子、參數組成，支援 AND/OR 群組。例如「收盤價低於近 252 日高點 20%」買進，「持倉報酬高於 20%」賣出。
2. **風險管理條件：**加入停損、移動停利、最長持有天數、每次投入比例及最大曝險。清楚說明同日同時觸發多個條件時的優先順序。
3. **儲存策略：**先用瀏覽器本機保存常用參數組合，後續再加入帳號同步；提供複製、改名、刪除和恢復預設值。
4. **穩健性檢查：**切分樣本內／樣本外期間、Walk-forward、參數敏感度熱圖，協助看出結果是否只在單一參數或期間成立。
5. **交易日誌與保存工作區：**保存模擬交易理由、策略版本、自選清單、回測設定與投資組合匯入資料，提供可還原的歷史紀錄。

### P3：擴展資料與選股能力

1. **成交量與波動：**需要 OHLCV 日資料後，再加入均量、價量、ATR、KD、MACD、ADX 等條件。
2. **公司基本面：**串接營收、EPS、殖利率、ROE 等可追溯歷史資料；必須使用當時已公布的資料日期，避免把後來才知道的數字帶入舊回測。
3. **法人與籌碼：**串接外資、投信、自營商買賣超、融資融券等歷史資料；標明來源、公告時間和缺漏區間。
4. **台股策略篩選器：**以 WantGoo 的條件分類方式作為 UX 參考，支援技術、基本面、籌碼、ETF 等條件組合、篩選結果與保存條件。資料未接通前，不顯示為可用條件。
5. **投資規劃與學習：**加入資產配置／再平衡、目標情境和 Monte Carlo、壓力測試、公司事件日曆及循序式練習；每個預測情境要列出假設和不確定性。
6. **社群／競賽：**等帳戶與隱私管理成熟後再推出策略報告分享、模擬挑戰和排行榜；允許匿名或私密模式，以回撤和風險調整指標搭配報酬評分。

### P4：即時行情、最佳五檔與 K 線

**資料來源先決條件：**TWSE OpenAPI 現有範例以盤後行情與日資料為主；不能把公開 OpenAPI 的存在等同於即時逐筆或最佳五檔授權。TWSE 將交易時間內資訊定義為即時資訊、延遲 20 分鐘以上者定義為延遲資訊；使用即時或延遲交易資訊需依其管理辦法簽約並確認費用。正式開發前，先確認展示對象、資料延遲、再散布授權、API 限額和商用條件，再選擇交易所核准管道、授權資訊商或券商 API。參考：[TWSE 資訊使用規範](https://www.twse.com.tw/zh/products/information/use.html)、[TWSE 交易資訊管理辦法](https://twse-regulation.twse.com.tw/TW/law/DAT08_print.aspx?FLCODE=FL007129)、[TWSE OpenAPI](https://openapi.twse.com.tw/)、[TPEx 市場交易看板](https://www.tpex.org.tw/zh-tw/market-trade.html)。

1. **即時／延遲報價卡：**最新成交價、漲跌、成交量、更新時間、資料來源和即時／延遲標籤；行情中斷時保留最後時間戳並標示資料過期。
2. **最佳五檔深度：**買賣各五檔價格與委託量，提供簡潔的深度條；只有來源授權明確涵蓋展示時才上線，不以延遲成交資料推造委託簿。
3. **盤中走勢與 K 線：**先做分時線和日 K，再擴充 1/5/15 分 K；顯示成交量副圖、十字游標、區間縮放與日期選擇。K 線週期只能由來源資料實際支援的頻率聚合。
4. **自訂圖表工作區：**使用者選擇標的、週期、主圖均線與副圖 RSI/MACD；保留版面、圖層和色彩的合理預設，手機版以簡化圖層與清楚時間標籤優先。
5. **技術架構：**行情供應商連線放在後端 adapter，不將 API 金鑰放進瀏覽器；後端正規化報價事件並以 WebSocket 或 SSE 推送給前端。用短期快取和重連機制控制供應商頻率，並保留資料來源、延遲和最後成功時間。
6. **與回測分開呈現：**即時看盤是目前市場資料；歷史回測是依已完成 K 棒計算。未收盤 K 棒可變動，不能直接混入已定稿回測績效；另提供「將圖表區間帶入回測」入口。

## UI/UX 建議

- **跨頁導覽分成研究和練習：**主導覽清楚提供「市場、研究、練習、投資組合、學習」入口；目前第一版未實作的頁面以路線圖呈現，不做只有標題的空白頁。
- **首頁兼作個人工作台：**顯示大盤／類股摘要、最近查看標的、未讀提醒、最近回測和虛擬帳戶摘要；使用者可自行隱藏或排序卡片。
- **虛擬下單回饋即時可讀：**送出前預估數量、成交金額、手續費、交易稅和剩餘現金；送出後顯示委託狀態，成交／拒絕／取消原因能從帳本追查。
- **分清三種金額：**虛擬帳戶資金、手動登錄的真實持倉、自訂回測的模擬資金使用不同標籤與色彩，不混算到同一總資產。
- **競賽排行榜看風險：**預設同時列出總報酬、最大回撤、波動和風險調整績效；展示排名期間、行情延遲與模擬規則。
- **設定區分步驟：**標的與期間 → 策略範本 → 策略參數 → 投入與成本；每個策略只顯示相關欄位，避免一次塞滿全部參數。
- **範本卡片說明規則：**每個範本顯示「何時買、何時賣、可調參數、適合觀察的市場型態」，不用把範本描述成推薦或保證獲利。
- **自訂條件用句子預覽：**使用者調整數字時，同步顯示完整語句，例如「收盤價距近一年高點回跌 20% 時買進；持倉報酬達 20% 時賣出」。
- **結果先摘要，再展開細節：**首屏呈現比較期間、資產成長曲線、期末資產、總報酬與最大回撤；下方提供交易清單、年度報酬、假設與資料來源。
- **互動式曲線：**可隱藏／顯示系列；游標移動時顯示日期、資產值和投入累計；同時提供可切換的權益與回撤圖。
- **公平比較標籤：**清楚列出每個標的的資料涵蓋日期、有效交易日、成本假設和已知公司行動調整。跨標的歷史起始日不同時，提供共同期間比較選項。
- **行動版：**把主要設定做成分段卡片，回測按鈕保持容易觸及；結果圖可左右滑動，績效表保留橫向捲動與欄位標題。
- **行情版面：**即時價、漲跌幅和市場狀態放在圖表上方；最佳五檔採兩欄對齊，買賣量以條狀背景比較；資料延遲和更新時間不可藏在次要頁面。
- **空狀態與載入狀態：**先顯示範本選擇和規則摘要；長期間載入時顯示目前資料標的／期間與取消操作，完成後自動捲至結果摘要。

## 回測正確性與資料治理

- 訊號只讀取當時可知的已完成資料；成交價、交易日曆、成本與現金流假設需固定且可檢視。
- 擴充技術指標前確認所需欄位和資料歷史；僅有收盤價時，不得假裝可以算出成交量或 K 線型態。
- 公司分割、合併、除權息和下市資料會影響長期回測。每個標的顯示已處理的公司行動範圍和未處理項目。
- 後端維持版本化 JSON API；策略引擎使用純函式，讓現行 Worker 和未來 Spring Boot 共用同一套契約與固定行情樣本。
- 對外顯示回測是歷史模擬，不構成投資建議；不可把最佳參數回測結果直接呈現為未來績效預測。

## 建議的完成驗收

1. 同一組條件重新執行時，策略規則、成本假設和績效數字可重現。
2. 使用者可輸入預設清單之外的 TWSE 代碼；至少選兩檔標的時，曲線與表格能正確辨認每個標的及其定期定額基準，無行情資料時顯示明確錯誤。
3. 每種策略都能顯示明確的買進、賣出定義和參數；自訂門檻改變後，結果有更新。
4. 回測中途遇到資料缺漏或上游失敗時，指出標的與日期區間，不回傳部分資料卻標成成功。
5. 手機、平板與桌面版都能完成「探索標的 → 選策略 → 執行回測 → 解讀結果」，並可從策略庫或標的探索跨頁帶入設定及返回恢復。
6. 虛擬交易的委託、成交、費用、持倉和帳戶餘額可以從逐筆事件重算，狀態變化可追蹤；任何模擬交易頁均明確標示虛擬資金，不會送出真實券商委託。
7. 多頁導覽在桌面與手機都可用；跨頁帶入標的／策略的網址可重現同一設定，且各頁都有載入、空資料、錯誤和權限狀態。
