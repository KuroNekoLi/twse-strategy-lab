# 產品機會評估：把個股圖表變成研究工作區

日期：2026-10-09
狀態：功能清單為待驗證假設；MA20／MA60 圖層及品牌色修整已實作，尚未經目標使用者研究
目標使用者：想用台股歷史資料理解標的、檢驗策略並接續研究的個人投資研究者

## 問題與預期結果

產品規劃將研究路徑定為「找標的 → 建立策略 → 歷史驗證 → 理解結果 → 保存與回顧」。目前程式已有標的搜尋、個股日線／K 線、回測及交易明細、研究設定、筆記、穩健性分析、紙上交易與決策練習。從介面與程式直接可見的缺口是：圖表雖可選日期，尚未提供常用趨勢圖層；個股走勢和回測交易沒有互相定位；設定保存並不保存行情或回測結果。

這些是產品檢視發現的工作流程缺口，不代表已證明使用者因此困難或需要特定功能。理想結果是讓使用者更容易把圖表觀察帶入可檢驗的研究，同時保留來源、期間及計算假設。

## 功能機會清單

優先序同時考慮核心研究價值、現有資料可用性、風險與實作成本；不是需求驗證或正式里程碑承諾。

| 優先 | 功能機會 | 預期使用者結果 | 依賴／風險 | 建議狀態 |
|---|---|---|---|---|
| P0 | 資料可用性與回測錯誤說明 | 執行前知道哪些標的／期間可研究；失敗時能分辨資料來源、授權、網路或輸入問題 | 需統一目錄支援狀態與歷史資料 API 的實際行為；不以模糊錯誤掩蓋行情失敗 | 優先修可靠性與說明；以失敗案例驗收 |
| P0 | 品牌色與互動色一致 | 一般導覽、CTA、連結與焦點狀態看起來屬於同一套視覺系統 | 依使用者截圖意見；磚紅用於品牌與操作強調，綠色保留為台股下跌語意；多策略圖例仍可使用有意義的系列色 | 本次已調整；需再以跨頁瀏覽器檢查 |

## 本次選擇與驗收條件

採用最小、可撤回的圖表增量：使用目前已載入的日收盤資料，讓使用者可以分別切換 MA20 和 MA60，並在走勢或 K 線模式疊加。所選日期摘要同步顯示該日的平均值；有效交易日數不足時不生成線或偽造讀值。均線是描述性指標，不應表述為買賣建議或獲利訊號。

- MA20 僅從當日及之前 19 個有效日收盤價計算；MA60 僅使用當日及之前 59 個有效日。
- 兩條均線可獨立開關，並能在走勢和 K 線模式使用。
- 日期滑桿改變時，所選日期的均線數值同步變化。
- 少於週期所需資料時不畫線，並以文字說明資料不足。
- TypeScript 型別檢查與 Angular production build 通過；瀏覽器可切換指標並檢查所選值。
- 一般導覽、連結、按鈕、表單焦點與均線工具的品牌強調使用磚紅；綠色只保留在下跌／虧損等市場語意，不用作一般操作裝飾。
- 不新增行情供應商、資料庫表、帳號、雲端保存或即時交易能力。既有歷史行情在公開展示／衍生使用上的資料授權仍未確認；本次均線只處理目前已提供的資料，不代表取得新的展示權利。

## 後續驗證建議

讓 5–7 位正在自行研究台股的使用者執行「查看個股、比較 MA20／MA60、選一個日期、說明自己看到什麼」任務；觀察其是否能正確解讀均線和所選日數值，並詢問這是否會改變他們接續回測的方式。若大多數人忽略均線或誤認為訊號，應優先做交易圖表互相定位或資料可用性說明，而不是再增加技術指標。
