# M1 回測 MVP：執行範圍與驗收

來源為 `產品規劃.md` 4.2、5.1 與 8；文件僅供範圍依據，不修改原 PRD。

## 交付目標

讓使用者能選取可識別的台股代碼、設定策略與成本，執行可解釋的策略／定期定額／買進持有比較，並閱讀風險、涵蓋期間與資料限制。依賴缺少來源或授權證據的功能要維持明確未支援或阻塞。

## 依賴及邊界

- 現行輸入允許輸入代碼，但沒有來源可證的上市股票／ETF 搜尋目錄與名稱；禁止以手刻樣本冒充完整目錄。
- M0 市月行情使用、保存和再散布授權尚未確認；M1 使用相同端點前仍是研究用途／發布 `BLOCKED`。
- 以現有月日收盤 API、NEXT_CLOSE 代理和版本化費用模型為基礎；不新增即時行情、券商委託或任何真實交易敘述。
- 使用者已要求 M0 後持續到 M4；M1 階段交付後按序展開 M2、M3、M4，不將尚未做的階段列作完成。

## M1 驗收條件

| ID | 條件 | 證據 |
|---|---|---|
| M1-01 | 明確表示目錄是否有權威來源；未有來源前不顯示為完整搜尋 | UI 與來源規格 |
| M1-02 | 以同一標的、期間、現金流及成本比較策略、定期定額、買進持有 | 引擎 Golden fixtures + HTTP/API |
| M1-03 | 報告期末資產、淨投入、淨損益、TWR、年化 TWR、最大回撤、波動、成交數與曲線 | 固定資料及邊界測試 |
| M1-04 | 每檔標的顯示實際觀察期間、筆數、來源、更新時間可用性及缺漏／日曆限制 | API contract + UI |
| M1-05 | 可匯出包含輸入、設定、版本、資料 hash、結果及限制的本機研究報告 | 可重現 JSON 匯出測試 |
| M1-06 | 桌機／小螢幕實際瀏覽器主要成功與錯誤流程通過 | Chrome evidence；無真機宣稱 |

目錄完整度、合法資料保存及發布宣稱須待證據，不以程式通過代替。使用者回饋研究亦不由自動化測試推定。

## 進度

### 目錄功能後續擴充（2026-10-09）

- supersedes 前文「15 分鐘記憶體快取」及「TPEx 尚未查核／接入」的目錄狀態：上市公司、上市基金與上櫃公司目錄會同步保存於資料庫；空目錄首次搜尋時載入，並每日排程更新。名稱以公開來源簡稱優先，支援代碼前綴及中文名稱搜尋。目錄資料可持久化不代表市場行情獲准保存。
- 實際本機 `local` profile 連線驗證：官方來源首次同步 2,259 筆；`005` 回傳 0050、0051 等 12 筆；`台` 回傳 114 筆，首頁包含台塑、台達電、台積電。結果數量隨上游資料變動，不視為長期 SLA。
- 上櫃公司目前可搜尋但不可帶入 TWSE 行情回測。此範圍不是所有台灣上市櫃商品的完整清單；TPEx 基金／ETF、興櫃及其他商品類別未涵蓋。
- Yahoo Finance 尚未作為標的主檔來源。官方交易所目錄已有公司及基金代碼、名稱與市場欄位；後續如要接 Yahoo，先核對其可用 API、授權與服務穩定性，再決定是否用於行情或補充資料。
- 合成上游的真實 Google Chrome 驗收證據位於 `docs/quality/evidence/m1-browser-catalog/`；該驗收確認 UI 和 API 契約，不等於以正式交易所資料完成瀏覽器驗收。

- 完成：引擎新增「買進持有」基準。首筆觀察收盤以整數股投入初始金額；後續每月資金保留現金，不再買入。這是刻意定義的比較方法，並非全額持有全部現金流的傳統買進持有；UI 會揭露這項差異。Golden fixture 驗證股數、費用、現金流與期末損益，HTTP 契約確認第三組結果存在。
- 完成：報告新增年化已實現波動度，以有限且非空日報酬樣本標準差乘 `sqrt(252)`；有效觀測少於兩筆回傳 `null`，計算版本已提升，測試涵蓋手算及缺值邊界。
- 完成：依已核對的開放授權上市公司／基金目錄實作應用內代碼與名稱搜尋、來源／OGDL 來源連結、更新頻率／出表／取得時間與限制揭露。後端只保留 15 分鐘記憶體快取的白名單目錄欄位；精確來源與有限授權範圍記於 `docs/specifications/DATA_LICENSING_MATRIX.md`，只適用目錄、不延伸至月歷史行情或回測報告。後端完整 verify 45 tests 通過，前端 typecheck/build 通過。獨立 code review 發現並修正 STOCK 標籤與 Angular zoneless 搜尋結果不更新，最終複審 `ACCEPT`。合成資料實際 Chrome 目錄驗收 9/9 PASS，見 `docs/quality/M1_CATALOG_BROWSER_REPORT.md`。
