# M4 遮蔽未來的歷史練習與穩健性分析：執行範圍與驗收

依據 `產品規劃.md` 4.5、13、17.2 章。先交付可重播、可檢查的練習切片；這不是投資建議，也不以一組歷史績效宣稱策略有效。

## 範圍決策

- 歷史練習每次只將目前時間點以前的資料提供給決策介面；前端、請求和回應均不得洩漏未來資料。使用者選擇觀望、買入或賣出後才推進一步。
- 只使用已在當次工作階段取得的資料；不長期保存行情或衍生結果。授權確認前不提供可攜匯出、分享或服務端歷史重播。
- 穩健性分析限定小型、明確列舉的參數／期間／成本矩陣，顯示樣本數、資料限制、成本假設及相對結果分布；避免以最佳組合排序造成過度擬合暗示。
- 復盤記錄保存使用者原始計畫與手動決策，不宣稱辨識心理或提供個人化投資建議。
- 條件編輯器、新聞、財報、即時行情及自動下單不在本切片範圍。

## 驗收條件

| ID | 條件 | 驗證 |
|---|---|---|
| M4-01 | 時間游標後的價格與衍生指標不進入 UI/API 可見內容 | 未來資料隔離測試 |
| M4-02 | 決策事件依序記錄，重播同一輸入得到相同狀態 | 確定性 replay fixtures |
| M4-03 | 穩健性矩陣有上限、參數合法性驗證及成本敏感度輸出 | Golden tests |
| M4-04 | 結果頁揭露期間、樣本、成本、資料缺漏與非預測限制 | 瀏覽器驗收 |
| M4-05 | 瀏覽器以實際合成資料操作成功與錯誤流程，並保存截圖／trace | 獨立 QA 證據 |
| M4-06 | 獨立 code review 與 license/privacy review | 獨立審查 |
