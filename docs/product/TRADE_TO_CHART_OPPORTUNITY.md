# 回測成交連結個股圖表：產品切片評估

日期：2026-10-10  
狀態：依使用者要求進入可逆前端實作；需求成效仍待使用者任務觀察。

## 使用者問題與預期結果

策略研究者在回測工作台看到成交日期、方向與理由後，還需要自行找標的、調整圖表日期並對照該段行情。預期改善是從一筆成交更快抵達相同標的與日期的歷史圖，並確認當日可用的 K 線；這是由既有產品流程與競品介面推導出的問題假設，未經訪談證實。

## 決策與取捨

先做單一標的成交連結。它建立在既有 API 回應與畫圖元件上，不增加新資料源、後端 schema 或即時資料承諾。按日期精確匹配；超出目前範圍時只擴至既有五年上限；找不到日期時顯示狀態而不默選最近 K 棒。多標的結果的逐筆成交不含標的代碼，因此本輪明確停用精確連結。

獨立決策挑戰支持限制在「標的和日期可確定」時才導向，並指出使用者完成任務的證據才能證明價值。若任務觀察顯示使用者很少查單筆成交，或日期／資料缺漏導致連結常不可用，則應退回評估其他切片。資料授權、公司行動及交易日曆完整性仍是市場資料層級的未知，本切片不改變這些限制。

## 驗收

1. 成交區塊用可讀欄位呈現本頁已展示的方向、訊號日期、成交日期、理由、數量與價格，仍揭露節錄規則。
2. 畫面節錄中的單一標的成交且日期為有效日曆日期時，連結指向該標的並帶成交日期 query parameter；中間未節錄的成交不提供連結。
3. 圖表先精確匹配日期；若日期比目前資料更早，先重取五年範圍；若依舊沒有該日，顯示未找到，不改選其他 K 棒。
4. 多標的組合不做錯誤映射，清楚說明逐筆成交尚無標的識別。
5. 不變更後端 API、資料庫 schema、行情來源或 CORS；連結及訊息可用鍵盤操作、窄螢幕可讀。

## 最小驗證與成功訊號

用一個真實使用者任務，請其由回測成交找到個股當日圖並說明交易背景。觀察能否在不提示下完成、是否辨認資料日期、遇到缺日／超範圍時是否理解提示，以及最常回看的成交欄位。沒有使用者樣本時只報工程驗收，不宣稱產品假設成立。若之後收集匿名使用量，須先定義隱私及事件收集方式；本切片不新增分析追蹤。

## 獨立工作紀錄

- Brainstorm facilitator：`/root/idea_facilitator`，提出交易回放、個股工作台、條件篩選、圖表標記、社群觀點五個方向；沒有修改檔案。
- Decision challenger：`/root/decision_challenger`，獨立提出標的唯一性、圖表日期覆蓋、競品不足以證明需求等反例；沒有修改檔案。
- 以上為可識別的分離 subagent 工作階段；其工作不是瀏覽器驗收或市場資料驗證。

## 工程與瀏覽器驗收紀錄

- 實際 Chrome 154.0.8037.98，macOS，`http://localhost:4200/#/backtest?symbol=0050`。以本機 Spring Boot `local` profile 呼叫 TWSE 歷史資料，期間設為 2025–2026，執行雙均線回測，展開成交節錄並點擊第一筆「查看 0050 當日圖表」。結果網址帶 `date=2025-05-26`；個股圖顯示「已選取成交日 2025-05-26」、收盤 180.65 元及該日 OHLCV。截圖在瀏覽器驗收工具的互動結果中擷取，未另外寫入 repo。
- 同一 Chrome 實際確認 2025 年日期會把 1 年範圍擴至 5 年並精確選取；2019-12-31 超出 5 年時顯示無該日 K 線且保留最後日期，不選最近 K 線；2024-02-30 顯示日期格式錯誤。
- 這是本機環境的一次端對端 `BROWSER_RUNTIME` 證據，不證明行情授權、交易日曆完整或回測財務有效性。多標的禁止導向、窄螢幕和鍵盤操作沒有在本次瀏覽器逐項測試；前端目前沒有配置 unit/e2e runner。
- 獨立 code reviewer 審閱實際 diff，指出節錄範圍、嚴格日曆日期驗證、訊號日欄位及歷史請求失敗時日期狀態等問題；已逐項修正並完成最終覆審，沒有剩餘問題。
