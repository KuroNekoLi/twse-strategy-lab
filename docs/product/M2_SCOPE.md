# M2 個人研究室：執行範圍與驗收

來源為 `產品規劃.md` 4.3。此階段先建立不需登入的本機研究設定保存；未取得市場資料留存權之前，不持久化行情、逐日帳務、成交清單、績效結果或完整 API 回應。

## 第一個交付切片

- 可在瀏覽器儲存命名研究設定、從設定建立新版本、載入與刪除。
- 僅保存使用者提供的代碼、策略參數、期間、投入與成本假設；不保存行情或回測結果。
- 明確提示「只在此裝置／瀏覽器」，清除瀏覽器資料會刪除設定；沒有登入或雲端同步。
- localStorage 讀取遇到無效 JSON、未知版本或儲存已滿時安全顯示錯誤，不覆蓋現有可恢復值。
- 保存資料結構有 schema version，載入時重新驗證合法欄位；不把 API 結果或任意 HTML 注入頁面。

## 尚不包含／依賴

M2 PRD 的研究歷史、結果差異及分享需保存／輸出由市場資料衍生的結果。待 TWSE 或替代供應商的精確資料授權確認其保存、使用者分享與重播範圍後再作決策；目前只支持設定版本，不得稱為可重現歷史回測，也不保證重跑數值相同。

## 驗收條件

| ID | 條件 | 證據 |
|---|---|---|
| M2-01 | 新增具名設定並能在 reload 後重載，全部輸入欄位精確恢復 | Chrome 瀏覽器互動／localStorage schema |
| M2-02 | 複製成新版本不改動舊版本；刪除指定項目不動其他設定 | 前端邏輯與瀏覽器檢查 |
| M2-03 | 只持久化定義過的設定欄位，不包含 API response、行情、結果曲線、每日資產或交易資料 | schema/code review 及 storage inspection |
| M2-04 | 無效／未知版本、配額錯誤有可見且可恢復行為 | 瀏覽器錯誤案例 |
| M2-05 | UI 說明本機保存與資料遺失風險；鍵盤與窄版可用 | 實際 Chrome 證據 |
| M2-06 | 獨立 review 審查存取、驗證與刪除邏輯 | Code Reviewer |

## 切片結果

本機設定切片已實作並通過 Chrome 12 項瀏覽器檢查，證據位於 `docs/quality/M2_BROWSER_REPORT.md` 及 `docs/quality/evidence/m2-browser/`。Code Reviewer 發現重複版本 ID 可能令一次刪除移除多個版本；已加入 ID 唯一性驗證並複審 `ACCEPT`。前端 typecheck/build 通過。

這不代表 M2 全部完成；研究歷史、結果比較、分享與帳號／同步仍未交付。
